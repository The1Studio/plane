# Fork SQL/ORM query-pattern audit — workload surfaces

**Coverage:** read `apps/api/plane/workload` and `apps/api/plane/workload_cache` in full (all production modules, tests, and migrations). 36 ORM/raw-SQL call sites reviewed in shippable code: `workload/service.py` (18), `workload/views.py` (7), `workload/rollup.py` (4 ORM + 1 raw `connection.cursor`), `workload/migrations/0004` (5), `workload_cache/signals.py` (1). Grep patterns: `.objects.`, `.raw(`, `connection.cursor`, `select_related`, `prefetch_related` — the last three have zero hits (bulk paths use `values_list`/`annotate`/`Exists` instead). Test-fixture `.objects.create/update` sites were scanned but excluded (setup code, not request paths); migration 0004 uses `values_list` + `bulk_create`, no loop queries. No N+1, no queries inside loops, no `len(qs)`, no queryset truthiness, and no unbounded large-table fetches: both materializing queries in `compute_workload` are sliced `[:ROW_GUARD + 1]` (service.py:582, service.py:600). All findings live in fork-owned apps; no upstream/core paths are in scope.

## Top findings

1. **service.py:58 — admin-check duplicated 2-3x per request.** The single cheapest win: every workload/estimate/rollup path re-runs the identical WorkspaceMember query. Hoist to one lookup per request and thread the flag through.
2. **service.py:155 — own-issue list materialized twice** for restricted-guest matrix requests, because `_scope_filter` is called for both `issue_id` and `id` variants. Compute once, pass in.
3. **service.py:367 + rollup.py:259 — giant literal IN lists** (50k and 10k ids) on the two hottest bulk paths. The surrounding code already names this cost (service.py:285); chunk or aggregate in SQL.
4. **rollup.py:221 — CTE rows folded in Python:** up to 10,001 rows fetched to compute per-root aggregates that a GROUP BY would return in single-digit rows.
5. **service.py:605 — `zero_estimate_count`** is a third full pass over WorkloadEstimate⋈Issue on every matrix request; fold it into the main scan as a conditional aggregate.
