## Top findings

1. **Prefetch missing `project_id` filter** — `plane/apps/api/plane/app/views/project/base.py:88-95`. Every project in `get_queryset()` is annotated with a `members_list` prefetch that pulls **all** active members of the entire workspace (no `project_id=OuterRef("pk")` on the inner queryset). `members_list` is then iterated at L227 to build `member_ids`. In a workspace with 1k members and 50 projects, a single project list view pays 1k×50 = 50k row hydrations for what should be 50. This is the single largest waste in scope.
2. **Per-row `WorkspaceMember` query in project-member add** — `plane/apps/api/plane/app/views/project/member.py:70-83`. Classic N+1: `for member in member_roles: WorkspaceMember.objects.get(...).role` issues one query per member being added. A single `.filter(member_id__in=...).values_list("member_id", "role")` replaces N round-trips with 1.
3. **`issues.update()` inside the issue loop, plus N async tasks** — `plane/apps/api/plane/app/views/estimate/base.py:193-210`. The same queryset is re-evaluated on every iteration so the UPDATE runs N times instead of once, and `issue_activity.delay()` queues one background task per affected issue with stale `current_instance` snapshots after the first iteration. Same defect in the `else` branch (lines 212-228) where N tasks are queued without any update.
4. **Chained `.select_related()` silently drops three joins** — `plane/apps/api/plane/app/views/project/base.py:502-503`. Django replaces on each `.select_related()` call, so the first call's `project`, `project__project_lead`, `project__default_assignee` joins are discarded; only `workspace`/`workspace__owner` survive. Any later access to `favorite.project.*` triggers a per-row follow-up query — a hidden N+1.
5. **Per-row `ProjectPage.objects.create()` in page duplicate** — `plane/apps/api/plane/app/views/page/base.py:604-611`. `for project_id in project_ids: ProjectPage.objects.create(...)` does N INSERTs inside a Python loop; a single `bulk_create` (with the same `ignore_conflicts=True` semantics) collapses N round-trips into 1.
