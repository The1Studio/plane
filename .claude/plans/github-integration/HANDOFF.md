## Key Decisions Made

- **Three-tier config scope** (user decision this session): instance-global default → per-workspace override → per-project override. Fixes the cross-workspace privilege leak the old instance-global-only design had (a workspace admin could edit rules other workspaces inherit). Instance tier gated by `InstanceAdminPermission`; workspace/project tiers by `@allow_permission(level="WORKSPACE")` via a real `<slug>` path segment.
- **Workspace override is project-agnostic** → shape-only validation (no state-existence check); state names are only validated at the project tier against that project's `State` rows.
- **URL mount unchanged** — routes stay under `/api/github/...` (webhook URL `/api/github/webhook/` preserved for the GitHub App config).
- Earlier P0–P2 decisions unchanged (fork-isolated app, service-token internal PATCH for state changes, bot-membership guard).
